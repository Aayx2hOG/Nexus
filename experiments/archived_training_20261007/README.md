# Archived training research — 7 October 2026

These scripts were removed from the active `training/` directory because they are
outside the dependency chain of the selected LightGBM + baseline AE packages.
Research-only tests are preserved beside them. Core tests from mixed modules
remain active; their original complete modules are saved here.

`manifest.json` records original paths and SHA-256 hashes. No model weights,
experiment outputs or data were removed. Staged/local source edits are preserved
byte-for-byte. This is a historical source snapshot, not a relocated runnable
pipeline: scripts assuming their original filesystem paths must be restored to
those paths before reproducing older experiments. Old reports may link to the
original paths; consult the manifest for their archived location.
